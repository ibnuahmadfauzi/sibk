# Pelacakan Pekerjaan

- Sebelum mulai, baca `docs/current-work.md`, periksa branch/status Git, dan catat
  checkpoint/task aktif bila berubah.
- Setelah task diverifikasi, perbarui task terakhir, gate, dan langkah berikutnya
  pada handoff; simpan bersama commit task.
- `docs/current-work.md` maksimal sekitar 100 baris untuk status berjalan dan blocker.
- `docs/development-log.md` hanya untuk ringkasan checkpoint/pekerjaan selesai.
- Jangan menggandakan progres panjang pada rules, workflows, atau laporan evidence.
- Screenshot per skenario dan workbook penelitian tidak diwajibkan; pengujian umum
  dan perlindungan hak akses server tetap dipertahankan.
