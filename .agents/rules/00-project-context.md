# Aplikasi BK — Aturan Workspace Antigravity

Aturan ini harus diaktifkan sebagai **Always On** untuk seluruh model yang dijalankan melalui Google Antigravity, termasuk Gemini, Sonnet, dan Opus.

Sebelum melakukan analisis, perencanaan, penulisan kode, atau review, muat dan ikuti kedua sumber berikut:

@../../docs/ai/00-start-here.md

@../../docs/ai/agent-operating-rules.md

Ketentuan singkat:

- Gunakan dokumen di `docs/` sebagai sumber konteks bersama.
- Audit repository sebelum menyimpulkan stack atau pola kode.
- Untuk frontend, gunakan Bootstrap dan token visual terpusat.
- Jangan mengubah backend saat mengerjakan frontend kecuali tugas menyatakannya.
- Catat keputusan UX baru di `docs/ux/decision-log.md`.
- Jangan mengisi keputusan domain BK yang belum sah dengan asumsi model.
- Jalankan pemeriksaan proyek sebelum menyatakan pekerjaan selesai.
