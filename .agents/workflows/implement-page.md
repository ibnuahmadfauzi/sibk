# Implement Ruang BK Page

Description: Implementasikan satu PG dari Penpot Hi-Fi.

## Input
Identifier PG dan nama halaman.

## Steps
1. Baca target PG di `22 — UI High-Fidelity Final`.
2. Baca pola relevan di `22.5 — Style Guide`.
3. Periksa komponen existing.
4. Reuse komponen jika setara.
5. Implementasikan hanya PG yang diminta.
6. Jangan redesign shell atau token global.
7. Pisahkan mock/service dari presentation component.
8. Gunakan service/repository interface + mock adapter bila backend belum tersedia.
9. Jangan membuat endpoint/backend.
10. Jalankan formatter, lint, dan build.
11. Buka route hasil implementasi.
12. Cek console, asset, overflow, dan layout desktop dasar.
13. Berhenti setelah validasi teknis.

Jangan melakukan iterasi visual otomatis berulang kecuali diminta.
