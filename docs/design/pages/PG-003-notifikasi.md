# PG-003 — Notifikasi

## Tujuan dan pengguna
Menampilkan pemberitahuan jadwal, penugasan, koreksi, atau perubahan penting kepada seluruh peran MVP (CASE-05; ASN-03; AUD-01).
## Requirement terkait

Hanya notifikasi milik pengguna; tautan tidak memperluas akses (AC-031). Data terkait terbatas.
