# PG-002 — Dashboard

## Tujuan dan pengguna
Menampilkan kondisi kerja menurut peran, scope, penugasan kasus, dan koordinasi Waka untuk Guru BK, Koordinator BK, dan Waka (DASH-01–DASH-03).
## Requirement terkait
AUTH-02; AUTH-05; DASH-01–DASH-03.
## Informasi, field, dan aksi wajib
Filter tahun ajaran tersinkron; jumlah murid, pelanggaran, ringkasan kategori/kelas, kasus belum ditindaklanjuti, jadwal terdekat, dan aktivitas (IT-004–IT-010). Rincian tetap memeriksa akses.
## State dan variasi peran
Muat, kosong, gagal, berhasil; Waka hanya agregat serta tautan kasus terkoordinasi (IT-010; UX-004, UX-010).
## Batas akses dan data sensitif
Guru BK/Koordinator hanya data berwenang; Waka agregat dan kasus terkoordinasi; Admin IT tidak otomatis (AC-002). Jadwal/kasus sensitif.
## Sumber desain
Low-fi: `PG-002 — Dashboard` (`lowfi-working`). High-fi: `PG-002 — Dashboard — Default` (`not-started`; tanpa UUID/ekspor). Arah visual: UX-018, bukan kontrak visual (design-page-map).
## Keputusan UX
UX-001, UX-004, UX-010, UX-011, UX-017.
## Validasi domain yang masih terbuka
Tidak ada yang menghalangi low-fi; rincian integrasi mengikuti VTI-01 dan VTI-02 saat implementasi.
## Gerbang berikutnya
Low-fi dapat disusun dalam batas scope; lanjut setelah review low-fi dan high-fi.
