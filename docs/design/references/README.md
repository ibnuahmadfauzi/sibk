# Referensi Arah Visual

Folder ini menyimpan tiga contoh `visual-direction-approved` yang memandu bahasa visual SIBK. Semua contoh perlu menerapkan koreksi pada [visual-language.md](../visual-language.md) saat diterjemahkan ke Penpot. Contoh tidak merupakan desain halaman final, ekspor high-fi, atau kontrak pixel-perfect.

| File | Pemetaan | Status | Batas penggunaan |
|---|---|---|---|
| `PG-001-login-visual-direction.png` | PG-001 — Login | `visual-direction-approved` | Arah umum login; bukan sumber visual frontend. |
| `PG-002-dashboard-visual-direction.png` | PG-002 — Dashboard | `visual-direction-approved` | Arah umum dashboard; bukan sumber visual frontend. |
| `PG-202-profil-murid-visual-direction.png` | PG-202 — Profil Murid | `visual-direction-approved` | Arah umum profil murid; bukan sumber visual frontend. |

Frontend hanya merujuk board atau ekspor halaman yang sudah `hifi-approved` sesuai [design-page-map.md](../design-page-map.md). Jangan menyalin nilai warna, spacing, font, radius, atau shadow dari PNG ini.
