# Peta Low-Fidelity dan High-Fidelity

Peta ini menghubungkan 26 unit antarmuka kanonik ke brief, keluarga board low-fi, dan keluarga board high-fi. `lowfi-approved` adalah kontrak UX; pada saat pembaruan ini seluruh board low-fi masih `lowfi-working`, sehingga belum boleh diklaim approved. Semua nama high-fi di bawah adalah nama kanonik yang akan dipakai ketika board dibuat; tidak ada UUID Penpot yang dicatat atau disimpulkan.
