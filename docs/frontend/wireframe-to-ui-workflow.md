# Workflow Wireframe ke UI — Riwayat

Dokumen ini merekam workflow lama dan bukan rute aktif frontend. Low-fidelity yang disetujui tetap merupakan kontrak UX untuk informasi, alur, aksi, state, hierarki, dan batas peran; ia bukan sumber visual UI produksi dan tidak boleh diterjemahkan langsung ke kode.

Untuk implementasi frontend, gunakan [workflow high-fidelity ke frontend](hifi-to-frontend-workflow.md). Aturan tahap, status, dan sumber kebenaran kanonik berada pada [design delivery pipeline](../design/design-delivery-pipeline.md).
